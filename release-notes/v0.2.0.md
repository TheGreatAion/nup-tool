### Packing a dump

- **Damaged dumps are flagged:** when you choose a dump folder, the app checks the game's program files in `exefs`. If one is shorter than it should be, you'll see which file and how much is missing. This is what happens when a dump is copied over FTP in text mode, which FileZilla does by default for files without an extension.
- **How to fix it:** copy the `exefs` folders again in binary mode (FileZilla: Transfer > Transfer type > Binary), then pack again.
- **A question before packing:** pressing Pack on a damaged dump asks whether to pack it anyway, since the game may not run from it.
