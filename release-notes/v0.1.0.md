First release of nup tool, a Windows app for packing, browsing and extracting NUP containers of unencrypted Switch game dumps.

### Installing

- **Installer:** run `nup-tool-setup-0.1.0.exe`. It installs for your user account without an admin prompt, and you can remove it from Windows' Installed apps list.
- **Portable:** unzip `nup-tool-0.1.0-portable.zip` and open `nup tool.exe`. Keep the `_internal` folder next to it.
- **Windows warning:** the app isn't signed, so SmartScreen may warn you. Choose **More info**, then **Run anyway**.

### Packing a dump

- **Dump folder to `.nup`:** drop a folder with `base`, `updates` and `dlc` onto the window and see which packages were found before packing.
- **Titles and icons:** set the title, publisher, display version, icon and translated titles while packing.
- **Split files:** pack the base game, each update and the DLC into separate files.
- **Progress:** see speed and time left. Canceling or a failed pack leaves no partial files behind, and existing files are never overwritten.

### Browsing a `.nup`

- **Contents:** browse packages, folders and files with their sizes and checksums.
- **Verify:** run a full check of every file, or a quick check of the structure.
- **Edit titles and icons:** change them in place without repacking. A failed save leaves the original file as it was.

### Extracting

- **Pick what you need:** extract selected files, or the whole container as a dump folder you can pack again.
- **Rescue:** recover the files from a container whose folder list is damaged.
- **Safe by default:** every extracted file is checked as it's written, and containers that try to write outside the chosen folder are refused.
